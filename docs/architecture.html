关键工程决策

  • 重量级对象全部懒加载 + 单例（dependencies.py）：embed / llm / reranker / vectorstore / index / retriever
  • 导入或删除后三层缓存联动失效：invalidate_index_cache + invalidate_retriever_cache + clear_cache
  • 全链路同步（同步处理器 + psycopg2 + 同步 httpx）；retrieval_use_async 必须关，否则第二次检索 nested async
  • 业务表与向量表分工：chunks 表供管理与溯源，data_fire_chunks 供向量检索（node_id = chunks.id）

降级策略（每一层都设计过）

  • 解析：pdfplumber → PyMuPDF → PaddleOCR，每级都要过文本质量分
  • 切块：SemanticSplitterNodeParser → SentenceSplitter
  • 缓存：Redis → 进程内 LRU → 直通（不缓存）
  • 精排：加载失败返回 None，检索链路自动跳过
  • 数据库：驱动缺失 → 内存 SQLite，保证 import 与单测不被环境阻断
  • LLM 未配 key：只告警不抛错，导入/检索链路仍可跑通
